## 4. Platform and game assets

- **Minecraft** names, trademarks, and in-game behavior belong to Mojang Studios / Microsoft. This software does not ship the Minecraft client or official game assets; conversion targets are resource packs you already own.
- Textures generated during conversion are derived from **packs you imported**; copyright remains with the original rights holders.
- **Reference data (regenerated from the official client)**: conversion rules rely on reference data such as "item model definition templates" and "canonical fingerprints of legacy vanilla models/blockstates". These are regenerated by this repository's scripts (`tools/gen-item-definitions.py`, `tools/gen-mc-reference.py`) from the **official Minecraft Java client jars / Mojang's official version manifest**. What is committed to source control is only pack-relative paths and SHA-256 digests of canonical JSON (or the JSON structure of vanilla item definitions); **no official textures, models, sounds, or other game asset files are included or distributed**. The data is used to recognise "unmodified vanilla files" and to generate equivalent definitions for the target version; official Minecraft assets remain the property of Mojang Studios / Microsoft, and using this software grants no right to redistribute them. Official Mojang client jars fetched by the generator exist only as a **local build-time cache** under `tools/.mc-cache/` (excluded via `.gitignore`); they are not distributed with the source tree, installer, or conversion output. Only the generator script and the path + SHA-256 data it produces, plus source metadata in `source.jars` (version, SHA-256 and byte size of each client jar; still no asset content), are committed or shipped.
